#  Hangman

Welcome to **Hangman**! This is a classic word-guessing game built completely in Python. 

---

## How to Play

The rules are simple:
1. The computer picks a secret word at random.
2. You'll see a series of blanks representing each letter in the word.
3. Guess a letter one at a time. 
4. If the letter is in the word, it will fill in the correct blank spaces. 
5. If it's wrong, you lose an attempt.
**Guess the full word before you run out of tries to win!**

---

## Getting Started

Follow these quick steps to get the game running locally on your machine:

### Prerequisites
Make sure you have [Python 3.x](https://www.python.org/) installed on your computer. You can check by running this in your terminal:
```bash
python --version
```
